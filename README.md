# 轻松英语写作 · Channel Intro

A 24-second, beat-synced channel intro: bold kinetic typography, a film-leader countdown,
bilingual English/中文 copy and a subscribe-and-bell ending. It is rendered entirely from code
with [Remotion](https://www.remotion.dev), and the soundtrack is original and synthesized.

**Video:** [`out/channel-intro.mp4`](out/channel-intro.mp4) · 1920×1080 · 60 fps · H.264 + AAC

## What happens

The track runs at 128 BPM and every cut, slam and camera punch lands on a beat.

| Time   | Beats | Scene                                                                    |
| ------ | ----- | ------------------------------------------------------------------------ |
| 0:00.0 | 0–4   | Greeting, one word per beat: HELLO · 你好 · WELCOME · 欢迎                  |
| 0:01.9 | 4–8   | 4-3-2-1 film-leader countdown while "EASY ENGLISH WRITING" decodes        |
| 0:03.8 | 8–12  | **Drop**: 轻松英语写作 slams in, subtitle bar wipes on                      |
| 0:05.6 | 12–16 | Tilted name stack that steps and recolors on every beat                  |
| 0:07.5 | 16–32 | Topic cards: GRAMMAR · VOCABULARY · SENTENCES · ESSAYS                   |
| 0:15.0 | 32–36 | Slogan WRITE / BETTER / ENGLISH with 轻松写出地道英文 typed vertically       |
| 0:16.9 | 36–40 | Breakdown: READY? · 准备好了吗？ · LET'S · WRITE!                           |
| 0:18.8 | 40–52 | **Final drop**: logo lockup, subscribe click, bell ring, sign-off, fade  |

## Make it yours

Everything on screen comes from **`src/config.ts`**: channel name, English subtitle, `@handle`,
logo badge, greeting, topics and captions, slogan, button labels, sign-off, and the four brand
colors. Chinese and English can be mixed in any field. Text is auto-fitted, so longer or shorter
words still fit the frame.

The one thing worth filling in is `handle`. It is empty by default, so the English subtitle
shows in its place under the logo and on the topic cards.

## Commands

Requires Node.js 18+.

```bash
npm install
npm run studio   # live preview in the browser; edits to src/config.ts show up instantly
npm run render   # writes out/channel-intro.mp4
```

The first render downloads a headless Chrome automatically.

## Soundtrack

`public/soundtrack.wav` is generated by `scripts/make_soundtrack.py` from the same beat grid as
the animation (`src/timeline.json`). Its risers, drops, whooshes, the mouse click and the bell
"ding" all hit on cue. It is synthesized from scratch, so it is royalty-free. To regenerate it
(Python 3 with `numpy` and `scipy`):

```bash
pip install numpy scipy
npm run music
```

To use your own music instead, replace `public/soundtrack.wav` and set `bpm` in
`src/timeline.json` to the song's tempo. The whole animation re-times itself so cuts stay on the
beat.

## Project layout

```
src/config.ts        ← text and colors (edit this)
src/timeline.json    tempo, frame rate, and where each section starts/ends (in beats)
src/scenes/          Intro, Name, Topics, Slogan, Hype, Outro
src/components/      camera shake/punch, glitch, marquee, film leader, HUD, subscribe/bell/cursor…
scripts/             soundtrack synthesizer
public/              fonts and soundtrack
```
